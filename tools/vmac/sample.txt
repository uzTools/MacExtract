# tools/vmac/sample.txt — the fixtures replayed on the emulated Mac Plus.
#
# Committed rather than generated at run time so that a 4 MB run and a 1 MB
# run months apart compare like for like, and so the per-fixture tables in
# FORMATS.md name a set anyone can reproduce.
#
# Selection rule: for each of the twelve formats, the smallest, largest and
# two intermediate fixtures by file size (the size spread is what exercises
# the memory budget), plus every fixture named individually in FORMATS.md or
# BLOCKERS.md.
#
# Run:  tools/vmac/run.py --list tools/vmac/sample.txt [--mem 1M]
#
# Nine fixtures were added on 2026-08-08, marked "see below". They had no
# oracle manifest until that day and so could never be replayed here; seven
# are THINK C projects holding both "X" and a real "X.rsrc", two carry a
# leading-'~' name. They qualify under the rule above by being named
# individually in BLOCKERS.md, and they are the only fixtures in this list
# whose shape can tell a fork-naming mistake from a correct extraction.
