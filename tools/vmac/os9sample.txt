# tools/vmac/os9sample.txt — the fixtures replayed on emulated Mac OS 9.2.
#
# Deliberately much smaller than sample.txt, which is the Mac Plus set. Each
# fixture here costs a whole boot of Mac OS 9 (~110 s on an idle host, plus a
# 2 GB image copy), where the Mini vMac harness replays a whole set inside one
# boot. So this samples for BREADTH OF FORMAT, not for the memory-budget
# spread that sample.txt exists to exercise: the 1 MB floor is a System 6
# question and the OS 9 machine has 512 MB.
#
# Selection rule: the smallest fixture of each format, plus three cases the
# size-ordered pick would have missed —
#
#   derived-DDT.sit          the smallest fixture carrying a real RESOURCE
#                            fork, which is what the whole M10 File Manager
#                            saga was about and what a data-fork-only sample
#                            never touches;
#   derived-XferIt_1.5b4.sea a self-extracting archive, and at 285 KB by far
#                            the largest thing here;
#   derived-DandStoQIF2.sea  DiskDoubler. It was DETECT-ONLY when this list
#                            was written and the expected outcome was a clean
#                            refusal; since M12 (2026-08-15) the engine
#                            extracts it. Nothing here needs changing for
#                            that: the harness compares the Mac against the
#                            Linux engine, so it follows the engine rather
#                            than a hardcoded verdict — but the row in
#                            FORMATS.md recording a refusal is a result from
#                            before M12, not a current one. Most `.sea` fixtures in the
#                            corpus turn out to be DiskDoubler or Now Compress
#                            rather than StuffIt, which the extension hides.
#
# Run:  tools/vmac/os9.py --list tools/vmac/os9sample.txt -o <dir> --launch
#
# Every entry is checked byte-for-byte, both forks, against the same engine's
# Linux output — see verify_output() in os9.py. Results in FORMATS.md.

# Eight formats and one refusal were added on 2026-08-27, when this tier
# was re-run for the first time since M12 (2026-08-15). Everything below
# the first block postdates that run. Three of them had no fixture at
# all — every other suite generates its subjects into a temporary
# directory — so tools/synth_os9.py writes one of each into fixtures/,
# and SOURCES.md regenerates them.
#
# One format is NOT here, and it is not a scope decision:
#
#   StuffIt SpaceSaver  the only specimens are the ones Aladdin's own
#                       compressor modules wrote under qemu-m68k, which
#                       live in the emulator cache and cannot be
#                       committed or regenerated on a clone. It HAS been
#                       run here, by path, on 2026-08-28 — 76,800 B
#                       byte-exact, and that first run found a name
#                       defect in the Mac shell (FORMATS.md, *SpaceSaver
#                       on Mac OS 9*). Repeat it with:
#                         os9.py ~/.cache/macextract/vmac/specimens/\
#                                spacesaver/modules/m4.ss --launch
#
# An encrypted entry is not in this list either, and does not belong in
# one: nothing in the corpus is encrypted, so `os9.py --encrypted`
# generates its own archive and answers the password dialog from the
# keyboard (2026-08-28; FORMATS.md, *An encrypted archive, through the
# dialog*). It is a run of its own, not a row here.
