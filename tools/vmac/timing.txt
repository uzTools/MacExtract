# tools/vmac/timing.txt — the fixtures timed at authentic Mac Plus speed.
#
# The correctness sweeps run the emulator all out, which says nothing about
# how long anything takes. This list is for the other question, the one a
# user actually asks: if I drop a .sit on a Mac Plus, do I wait one minute or
# twenty? It is deliberately SMALL — one fixture per format, chosen large
# rather than typical so the number is an upper bound people can plan
# around — because at 1x each fixture costs its real Mac Plus time and the
# full 44 would take all day.
#
# Run:  tools/vmac/run.py --emu mv-4M-1x --poll 3 --timeout 900 \
#           --list tools/vmac/timing.txt --json timing.json
#
# run.py splits boot from extraction (it can see the "alive" grid the app
# paints before it touches a disk), so the extract column is the archive
# alone.

# --- StuffIt 5 / Arsenic, added 2026-08-07 --------------------------------
# The list above samples StuffIt 5 with derived-KeyGraphics.sit (4,611 B),
# which is far too small to make the decoder fall back to its low-memory
# inverse BWT — so it measured the fast path and nothing else. This one does
# reach the fallback at 1 MB, and is the only Arsenic 1x figure there is:
#
#     tools/vmac/run.py --emu mv-4M-1x --mem 4M ...   537 s  (fast table)
#     tools/vmac/run.py --emu mv-1M-1x --mem 1M ...   927 s  (sampled index)
#
